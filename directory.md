# Casper AI directory

Every AI capability for the Casper Network that this repository lists: documentation indexes, MCP servers, agent skills, plugins, APIs and SDKs, from across the ecosystem. It is generated from https://github.com/msanlisavas/casper-llms/blob/main/catalog.json, and a weekly check confirms that each endpoint still answers and each entry's documentation is still readable. To list a capability, see https://github.com/msanlisavas/casper-llms/blob/main/CONTRIBUTING.md.

Listing is not an endorsement or a security audit. Entries are checked against the listing rules and probed weekly; their code is not reviewed. Many are early projects that run only on testnet. Read an entry's caution and its source before giving it funds or keys.

Entries marked "maintained here" are published by this repository's maintainer.

### AgentPay (Casper x402 charge checker)

Stdio MCP server and CLI that check a Casper testnet x402 charge before the buyer signs (PAY, REVIEW or BLOCK), verify the settled transaction and issue verifiable receipts; it blocks mainnet charges. Also sells token and account evidence reports over x402. Buyer keys stay local.

- **URL:** https://www.npmjs.com/package/@timidan/agentpay-mcp
- **Hosting:** Self-hosted
- **Transport:** stdio
- **Authentication:** no key, API key, x402 per call
- **Pricing:** Free and paid - Quote, payment-status and proof tools are free. Protected tools need a scoped AgentPay token; evidence reports are paid over x402 in testnet WCSPR (0.00001 per report on 2026-09-10).
- **Networks:** testnet
- **Publisher:** [Timidan](https://github.com/Timidan)
- **Documentation:** https://github.com/Timidan/agentpay-trust-pass
- **Source:** https://github.com/Timidan/agentpay-trust-pass (MIT)
- **Install:** `npx --yes @timidan/agentpay-mcp@0.1.2`

## APIs and payments

### CasperAI API

HTTP API that streams a verified, cited answer about the Casper Network as Server-Sent Events (POST /v1/chat), paid with a prepaid API key or x402 per query. The same engine runs the CasperAI web chat.

- **Endpoint:** https://casperai.ekolsoft.com/v1/chat
- **Authentication:** API key, x402 per call
- **Pricing:** Paid - Charged per delivered answer from a prepaid API key, or by x402 on Casper mainnet; refusals are never charged.
- **Networks:** mainnet, testnet
- **Publisher:** [msanlisavas](https://github.com/msanlisavas) (maintained here)
- **Documentation:** https://casperai.ekolsoft.com

### CSPR.cloud x402 facilitator

Hosted x402 facilitator from CSPR.cloud that verifies and settles x402 v2 'exact' payments (EIP-712-signed CEP-18 transfer_with_authorization) on Casper mainnet and testnet via /supported, /verify and /settle; needs a CSPR.cloud access token.

- **Endpoint:** https://x402-facilitator.cspr.cloud
- **Authentication:** API key
- **Pricing:** Free and paid - Settlements count against the caller's CSPR.cloud plan: Free includes 25 mainnet and 1,000 testnet settlements a month, Pro ($199/mo) 2,500 and 10,000 (cspr.build/pricing).
- **Networks:** mainnet, testnet
- **Publisher:** [MAKE Software](https://makegroup.io)
- **Documentation:** https://docs.cspr.cloud/x402-facilitator-api/reference

### Magen3 Agent Gateway

Pre-execution firewall API for autonomous agents: an agent submits a transaction intent and gets Allowed, Blocked or Review Required from deterministic policy checks, with decisions recorded as proofs on Casper Testnet. It does not take user keys or sign user transactions.

- **Endpoint:** https://magen3-production.up.railway.app

- **Pricing:** Free

- **Publisher:** [zicjoe](https://github.com/zicjoe)

- **Install:** `pnpm add @magen3/sdk@beta`

### Tab402

x402 pay-per-call rail on Casper testnet in front of Deepgram text-to-speech and cost-routed Gemini completions; the upstream runs only after on-chain settlement. Agents sign locally, but the dashboard's quick-start key is generated server-side.

**Caution:** The dashboard's quick-start key is generated on Tab402's server, so the service knows it; sign with a key you created yourself.

- **Endpoint:** https://tab402.fly.dev
- **Authentication:** x402 per call
- **Pricing:** Paid - Prices are in Tab402's own testnet CEP-18 token, which its dashboard hands out free: /v1/speak costs 0.02 plus 0.0006 per character, capped at 1.0; /v1/quote is free.
- **Networks:** testnet
- **Publisher:** [Eienel](https://github.com/Eienel)
- **Documentation:** https://github.com/Eienel/tab402
- **Source:** https://github.com/Eienel/tab402 (MIT)
